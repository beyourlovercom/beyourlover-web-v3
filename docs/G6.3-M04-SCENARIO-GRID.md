Status: LOCKED — Owner Desktop + Mobile + Implementation UAT PASS.

## Locked purpose
- M04 presents real-life product scenarios / contexts of use.
- It must not become another feature grid.
- One scenario is visually dominant; supporting scenarios are secondary.

## Desktop
- One primary scenario card.
- Two supporting scenario cards.
- Asymmetric 1 + 2 composition.
- Strong media-first hierarchy.

## Mobile
- Primary scenario is independent and full-width.
- Only supporting scenarios enter the horizontal rail.
- Do not place the primary card inside the horizontal rail.
- Horizontal rail must not create document-level horizontal overflow.

## Content
- Product-specific real media and copy are supplied by module configuration.
- Placeholder media/copy must never be treated as production content.
- Layout/component code is shared; products only replace configured content.
