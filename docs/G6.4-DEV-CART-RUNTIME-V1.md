# Dev Cart Runtime V1

## Goal

Make the Dev Cart page code-owned by BYL V3 instead of rendering historical page content that still contains Smart Coupons / BOGO blocks and localdev asset references.

## Ownership

- WooCommerce owns cart state, quantities, coupon processing, totals, shipping calculation and the checkout URL.
- BYL V3 owns page composition and presentation.
- Andy Commerce owns reusable checkout / shipping promotion policy.
- The historical WordPress Cart page body remains untouched for rollback but is not rendered by the dedicated theme template.

## Runtime

`theme/beyourlover-v3/page-cart.php` renders the native WooCommerce cart shortcode inside the canonical BYL V3 commerce container.

`assets/css/cart.css` provides responsive presentation only.

## Safety

- no database mutation
- no Woo order writes
- no coupon rule mutation
- no payment configuration changes
- no Production www changes

## UAT

Dev Owner UAT should verify:
1. cart item image/name/price/quantity/remove
2. coupon field
3. totals and shipping area
4. Proceed to checkout
5. 390px mobile readability / no horizontal overflow
6. no Smart Coupons / BOGO legacy block
7. no localdev.beyourlover.com asset references in rendered Cart HTML
