# G6.3 — Product Detail V3

Status: **implementation candidate — local technical gates pending**.

## Contract
- Keep WordPress/WooCommerce product and variation IDs, URLs, canonical/SEO ownership and commerce semantics unchanged.
- Product surface consumes the `commerce` shell profile defined by G6.2.5.
- BYL V3 owns presentation; WooCommerce remains authoritative for product type, price, stock, variations and add-to-cart behavior.
- Preserve stored ACF `productname` / `subtitle` semantics and `_custom_rich_text` blocks.
- Keep reviews/comments and related-product queries native to WooCommerce.
- Use R2-aware media helpers already established by V3.
- Do not rewrite Checkout, Payment Router, order flows or Production data in G6.3.

## Candidate implementation
- Purpose-built `woocommerce/single-product.php`; no Shoptimizer DOM/CSS dependency.
- Responsive product gallery, sticky desktop purchase summary, native Woo add-to-cart/variation form, reviews, rich content and related G5 Product Cards.
- Woo structured product data is explicitly generated for the rebuilt template.
- Product-only CSS is conditionally enqueued.

## Required gates
- PHP syntax lint for all changed PHP files.
- Simple + variable product render smoke on localnew.
- 1440 / 768 / 390: no horizontal overflow; purchase controls usable and >=44px touch target where applicable.
- Variation selection + add-to-cart semantics remain native Woo and cart count refresh is verified.
- Product image/R2 requests return successfully; first hero image is eager, remaining gallery images lazy.
- Product shell resolves Commerce/Commerce.
- Stored productname/subtitle/_custom_rich_text data renders when present.
- Rank Math/canonical identity unchanged.
- Production untouched until later cutover gate.
