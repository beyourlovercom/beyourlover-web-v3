## Canonical purpose
- One reusable Feature Gallery replaces legacy section5 / section10 / section11 variants.
- Variants are configuration, not separate modules.
- Supported visual variants: light / dark / card.
- Shared interaction engine: next / previous / next-card preview / count / optional detail expansion.

## Default state
- Real feature media.
- Feature title.
- Short verified summary.
- Current position indicator.

## Feature Detail State
- + appears only when a verified detail field exists.
- Clicking + expands the current feature detail.
- Media visually recedes; detailed text becomes the primary content.
- + rotates into close state.
- Clicking again restores the default state.
- Changing feature automatically closes the expanded state.
- Detail state must not change the semantic meaning of the feature.

## Desktop
- Large active card + visible next-card preview.
- Arrow navigation and count.
- Next-card preview may advance the gallery.
- Expandable detail remains within the active card.

## Mobile
- Active card is near-full-width.
- Next feature is partially visible to indicate horizontal progression.
- 48px touch target for +.
- Arrow navigation and count remain available.
- Mobile composition is independently tuned, not a squeezed desktop layout.
