# G6.3 M01 — Campaign Hero DRAFT

Status: LOCKED — Owner Visual UAT PASS (2026-09-17).
Scope: Product Detail Module System V1 / content module M01 only.
Reference product: Naughty Clock Pink.
Reference method: Apple MacBook Air hero composition, not Apple branding.

## 1. Role

M01 is the first editorial story module after the fixed Woo Commerce Core.
It answers one question only: “What is the emotional idea of this product?”
It does not repeat price, variation, reviews, specifications, mode counts, shipping, or FAQ.

## 2. Naughty Clock Pink message

Eyebrow: NAUGHTY CLOCK
Headline: Every Second Has A Secret
Supporting copy: An everyday alarm clock with pleasure you’ll want to wake up to.
Primary media: current Naughty Clock Pink campaign banner / product visual.
CTA: none by default; Commerce Core already owns purchase CTA.

## 3. Composition

Desktop uses a centered two-stage composition inside one module viewport.
Stage A is copy-first: centered eyebrow, headline, and one short supporting sentence with generous negative space.
Stage B is media-first: one dominant campaign visual centered below the copy, never a collage of secondary selling points.
The visual may bleed wider than the text column but remains inside the canonical page stage.

Target desktop content width: 1200–1320px.
Target text measure: 620–760px.
Target module height: approximately 88–100svh depending on asset ratio.
Side gutters remain visible at all desktop sizes.

## 4. Responsive contract

Tablet keeps the same hierarchy but reduces text width and media scale; no side-by-side compression.
Mobile reorders nothing: eyebrow → headline → supporting copy → media.
Mobile uses 20–24px side gutters, full-width media inside those gutters, and no forced desktop aspect ratio.
Headline must wrap naturally; manual `<br>` is content configuration only when explicitly approved.
No horizontal carousel, no floating purchase controls, and no secondary cards inside M01.

## 5. Media behavior

Preferred media is responsive picture or short muted motion with a static fallback.
If motion is supplied, it plays once on entry, respects reduced-motion, and never blocks first render.
Desktop/tablet/mobile assets may differ when composition requires it.
The media stage owns the visual focus; text never overlays critical product detail unless the approved asset was designed for overlay.
