# G6.3 M02 — Highlights Gallery

Status: LOCKED — Owner Visual UAT PASS (2026-09-17).
Scope: Product Detail Module System V1 / content module M02 only.
Reference product: Naughty Clock Pink.
Reference pattern: Apple-style “Get the highlights” horizontal story gallery, not Apple branding.

## 1. Role

M02 surfaces 3–5 high-value product highlights after M01.
Each card communicates exactly one idea with one dominant visual.
The module must never collapse into a generic equal-width three-card ecommerce grid.

## 2. Naughty Clock Pink canonical content

- 2-in-1 Design
- Cute, Yet Discreet
- A Gift for Special Moments

Content and media come from the existing approved Naughty Clock Pink design assets.
## 3. Layout contract

Desktop: oversized horizontal cards within a centered stage; the active card dominates and the next card remains partially visible as an affordance.
Tablet: preserve horizontal browsing with a smaller card width; do not convert to a dense multi-column grid.
Mobile: one large card at a time with a visible next-card edge; touch scrolling is primary, arrows are optional secondary controls.
Canonical page gutters remain visible at all widths.

## 4. Interaction contract

Native horizontal scroll is the baseline behavior.
Optional previous/next buttons may enhance desktop usability but must not be required to access content.
Use scroll-snap for stable card resting positions.
Respect reduced-motion; no autoplay carousel.
Keyboard focus order follows document order and every card remains reachable without drag gestures.
