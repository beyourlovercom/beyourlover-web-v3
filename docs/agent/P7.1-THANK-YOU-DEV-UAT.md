## Implementation
- Theme-only, no new plugin. Woo override: `theme/beyourlover-v3/woocommerce/checkout/thankyou.php`; scoped stylesheet: `assets/css/thank-you.css`; bootstrap: `inc/thank-you.php` and one isolated require in `functions.php`; pure ETA helper: `inc/thank-you-estimate.php`.
- All order IDs, names, product images, quantities, totals, addresses, paid status and payment method read from Woo's supplied `WC_Order`. No static #39923 data in code. No “confirmation email sent” message because Dev blocks email.
- Maintain Woo's `woocommerce_before_thankyou`, gateway-specific `woocommerce_thankyou_<method>`, and general `woocommerce_thankyou` integration hooks. Suppress only WooCommerce's duplicate core order-details output.
- Pending/failed/cancelled/refunded never show “Payment successful” or a dated delivery promise. No order creation, payment retry, DB write or dispatch.

## ETA V1 contract
Reference: https://www.beyourlover.com/shipping-policies/ (shipping origin/estimated windows published 2025): **US 3–5 business days transit**, **European countries 5–7**, **other destinations 7–15**, plus **24–48 hour warehouse dispatch**. This V1 budgets 1–2 preparation *business* days and excludes weekends, and provides a range rather than a guarantee.
- US: built-in US federal public holidays and observed days, including adjacent-year observation, e.g. Columbus Day 2026-10-12. For the isolated US order created 2026-10-09, dynamic expected range is **2026-10-16 to 2026-10-21**, not the sample mockup's illustrative Oct 16–20.
- Other destinations: do **not** pretend to have complete local public holidays. If no verified country/warehouse closure calendar is configured, display `5–7 business days after dispatch` or `7–15 business days after dispatch` instead of fabricated absolute dates.
- Site/operator can supply a **complete verified destination-year holiday calendar** via WP filter `byl_v3_ty_holidays` (an array `YYYY-MM-DD => holiday name` with arguments country and order). That enables bounded dates outside US. Ensure all relevant local and warehouse shutdowns are represented before enabling. This is an integration extension point, not an assertion that live calendars are provisioned.
- Estimates are policy guidance, not carrier commitments. Subsequent shipping method/class/pick-pack optimization is a separate later change.
