- `enabled=true`; `expires_at` strictly in the future and <=1 hour away

## External effect guard
A plugin or ERP connector may have background integration not exposed by Woo Webhooks. Before transaction creation, confirm Dev has no live ERP inbound route or outbound order integration. Test records must never be treated as real money or fulfillable orders.

## Stop conditions
Stop and disable the temporary gate if a real/live provider credential is detected in the active test rail, if non-test users can see any payment method, if Woo emits an outbound customer email/ERP shipment, if a real monetary charge occurs, or if test orders exceed the cap. Owner has not approved live payments, marketing mail or www cutover.
